# Call Centre Data Analysis in Excel

## Project Overview

➤ This project analyzes call center performance data to identify key trends and improve operational efficiency. Using Excel, the dataset was cleaned, processed, and visualized through a dynamic dashboard to derive meaningful insights.

## Objectives

➤ Evaluate call center efficiency by analyzing key metrics such as call volume, agent performance, and customer satisfaction.

➤ Identify peak call hours and optimize staffing levels accordingly.

➤ Assess customer satisfaction scores to enhance service quality.

➤ Create an interactive dashboard for quick decision-making.

## Dataset

➤ The dataset contains call logs with the following key attributes:
  - Call ID
  - Agent Name
  - Call Start Time & End Time
  - Call Duration
  - Issue Type
  - Customer Satisfaction Score
  - Resolution Status

## Methodology

➤ **Data Cleaning & Preparation:**
  - Removed duplicate entries and missing values.
  - Standardized date and time formats.
  
➤ **Data Analysis:**
  - Used formulas such as `SUMIF`, `COUNTIF`, `AVERAGEIF`, and `INDEX-MATCH` to compute key metrics.
  - Analyzed call trends to determine high and low traffic periods.
  - Evaluated agent performance based on call resolution rates and customer feedback.
  
➤ **Dashboard Creation:**
  - Utilized Pivot Tables and Pivot Charts for interactive reporting.
  - Implemented slicers for dynamic filtering by agent, date, and issue type.
  - Applied Conditional Formatting to highlight critical KPIs.

## Key Insights

➤ Identified peak call hours, helping in workforce optimization.

➤ Recognized top-performing agents based on customer satisfaction and resolution efficiency.

➤ Highlighted common customer issues, assisting in proactive service improvements.

## Tools & Technologies Used

➤ **Microsoft Excel** (Pivot Tables, Charts, Conditional Formatting, Formulas)

➤ **Data Cleaning Techniques** (Removing duplicates, handling missing values)

➤ **Visualization Techniques** (Dynamic dashboards, slicers, interactive charts)
